# ☕ Coffee Ordering System

**Created by Mashal Khan**

A simple Coffee Ordering System built with Python using Object-Oriented Programming (OOP). This project allows users to view a coffee menu, add coffee to their order, calculate the total price, view their order, and confirm or cancel checkout.

## ✨ Features

- Display a coffee menu with prices.
- Add coffee items to an order.
- View all selected items.
- Calculate the total bill automatically.
- Checkout with confirmation.
- Clear the cart after a confirmed order.
- Handle invalid menu choices.
- Use Python classes and methods.

## 🛠️ Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
- Lists
- Loops and conditional statements
- Functions and methods

## ▶️ How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the Python file:

```bash
python coffee_ordering.py
```
